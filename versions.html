IFMachine

Version history

1.6.0

  • Screen reader mode reads each turn aloud without being cut off by typing.
  • First pass on map tab accessibility.
  • Story intro text is no longer skipped by read aloud at story start.
  • Read aloud has fixed Read aloud, Pause and Read status buttons for TalkBack users.
  • Cloud save dialogs and upload progress are spoken.
  • Maze exits that loop back are marked on the map.
  • The map no longer repeats room descriptions the story pane already shows.
  • Bug: Read aloud no longer loops between pause and resume under TalkBack.
  • Other bug fixes.

1.5.0

  • Much improved support for TalkBack users.
  • Enable text to speech engine selection.
  • Moved status into main game pane and improved rendering.
  • Status lines are sized to your screen rather than squeezed to fit.
  • Bug: A game left in a menu keeps its screen when you return to it.
  • Other bug fixes.

1.4.0

  • IFMachine mapping handles dynamically named rooms.
  • The save dialog lists your saves, and tapping one replaces it.
  • Improved format styling handling in Glulx and Z-code.
  • Battery usage optimizations.
  • Improved mapping resiliency.
  • Bug: Room descriptions appear the first time you enter a room in Glulx games.
  • Bug: Mapping no longer says it resumed when it never stopped.
  • Bug: A learned map survives restoring an older save.
  • Other bug fixes.

1.3.1

  • The option to share a learned map appears only on the Map tab, once the map has enough rooms.
  • Game sound is muted while the app is in the background.
  • Bug: Returning to a Glulx game no longer repeats your last command.
  • Bug: The first row of an in game menu keeps its indent.
  • Other bug fixes.

1.3.0

  • In game menus update in place as the cursor moves.
  • Preserve game-cleared screens behind a divider.
  • Improved game status bar handling.
  • Bug: A missing library catalog story can be recovered.
  • IFDB listings with multiple supported formats present a chooser.
  • Bug: Learned maps could be lost during restart/reload.
  • Bug: Keys no longer stop working after focus moves at a press a key prompt.
  • Other bug fixes.

1.2.1

  • Maps now work in many Glulx games.
  • IFMachine attempts to learn how to map new games.
  • Edit a room's exits from the map to lock one, remove one, or change the command it walks with.
  • Library rows show cloud save status.
  • Implemented missing special keys support in Z-Machine games.
  • Bug fixes.
  • Fixed a couple memory leaks.

1.2.0

  • Maps now work in many Glulx games.
  • IFMachine attempts to learn how to map new games.
  • Edit a room's exits from the map to lock one, remove one, or change the command it walks with.
  • Library rows show cloud save status.
  • Implemented missing special keys support in Z-Machine games.
  • Bug fixes.

1.1.0

  • The map no longer changes layout when you reopen a game.
  • Rooms are grouped by how they connect to each other.
  • Library rows now show a map support icon.
  • Maps now work in more Z-machine games.
  • A warning if a multi-step move would create holes in the map.
  • IFDB search prioritizes title matches.
  • Some games are missing system tags, and search can now include them.
  • Typing look on the Map tab shows the room description again.
  • Bug: Saving a game and reopening it no longer destroys your map.
  • Bug: Cloud saves keep uploading after you delete a game's file from Drive.
  • Bug: An exit that loops back to the same room is no longer drawn as a dead end.

1.0.2

  • Maps now work in more Z-machine games.
  • Copy a map route to the clipboard.
  • Paste from the clipboard into your command.
  • Bug: Closing the route banner now stops the automatic walk.

1.0.1

  • Improved performance for image rendering.
  • Game artwork and title screens no longer shrink on phones.
  • Improved support for hardware keyboards.
  • The map buttons now explain themselves the first time you open it.
  • Tap a map connection to see where it leads, then close the banner.
  • Bug: Keys and taps no longer stop working after a keypress at a busy prompt.
  • Bug: The press a key prompt no longer flickers.
  • Bug: Room descriptions on the map now capture the full text. Type look to refresh an old one.
  • Bug: Close buttons on banners and panels are easier to hit.

1.0.0

  • Better graphics resolution in games that display them.
  • Better command editing in CRT and Retro themes.
  • Improved typography settings.
  • Bug: The problem report screen now lays out correctly on more devices.
  • Bug: Android system bar no longer washed out.
  • Bug: Read aloud during map auto navigation now speaks only the room you arrive in.
  • Bug: Fixed a stray blank page when a game opens its map.

0.6.0

  • Search the map to create routes and navigate automatically.
  • Tips introduce hidden gestures as you play.
  • New gesture guide in About.
  • Cleaner map lines when nearby connections run side by side.
  • Bug: Tapping a word to add it to your command no longer opens the keyboard.
  • Bug: Font choice now works on CRT themes, with a new Theme default option.
  • Bug: Audio playback fixed on older phones.

0.5.0

  • Read stories aloud with a choice of voice, speed, and pitch (alpha).
  • Choose what tapping or holding a word does, with a per-story action menu.
  • Long press now opens the action menu by default, and can be changed back in settings.
  • Time-based games show a clock in the status bar.
  • More reliable saves and story matching.
  • Fewer wrong characters in some games.
  • Various interpreter and display fixes.

0.4.4

  • Summon the keyboard and customize controls right from the navigation panel.
  • IFDB downloads now pick the right story file when an archive holds several.
  • Fixed garbled punctuation and line breaks in some games' text.
  • Fixed crashes in some games when an action referred to nothing.

0.4.3

  • Maps now use the Subway layout by default.

0.4.2

  • Choose your color theme the first time you open the app.
  • Maps now mark exits you cannot currently reach.
  • Map highlights use your chosen theme color.
  • Downloads always use a secure connection.

0.4.1

  • Tap any map connection to highlight where it leads.
  • Cleaner automap layout when rooms share several connections.
  • Fixed named saves being overwritten when syncing across devices.
  • Crisper monospace text on the Retro Desktop.
